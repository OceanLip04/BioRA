# PDF → 科学研究图谱（个人 Mac 版）

## 0.13.0：Discussion 收束、真实推理层级、图面板逻辑

新的 API 阅读契约增加 `discussion:{summary,origin,source_pages}`、`figure_panels`、`panel_links`。图谱 `mainline` 的每项增加 `role:result/discussion`；有论断的论文图谱必须以唯一 `discussion` 收束，综合原文解释模型、适用范围、局限与未解问题，不冒充另一项实测结果。没有明确讨论章节时，只允许标记为 inferred 的审慎综合。

逐树 depth audit 区分观察比较、局部解释、独立对照／读数的整合、机制或更广泛发现、最终讨论；允许真实的三级、四级及更深层级，不要求最低层数，不接受同义改写凑层级。原子实验仍不能直连任何主线节点，证据 DAG 的无环校验与跨树共享保持不变。

文献阅读库新增「图面板逻辑」，与「研究主线 / 详细阅读 / 论证画布」并列。面板结构为 `key,figure_ref,panel_label,title,question,observed_result,interpretation,limitations,method_keys,finding_keys,source_pages`；真实观察需关联真实 finding，示意图不编造测量。图注／文字推断必须承认未见像素，不从不可读图形估计数值。`panel_links` 为 `from_panel,to_panel,kind,explanation,limitations,origin,source_pages`；kind 仅 `supports,contradicts,motivates,controls_for,extends`。关系带具体论证、解释边界与来源，图面板相邻不自动意味着支持或因果。

图面板画布按图分列、面板分行，支持既有缩放／平移、选择详情、关联高亮及逐边文本核对。先前面板引出后续检验、后续面板又挑战先前解释的反馈关系可并存：它们是阅读逻辑，不转换为必须无环的科学证明 DAG。图面板内容与布局目前只读，不回写用户科学问题。

默认结论树交替在主线上／下方生长，同侧树保留防重叠间距、异侧树复用横向空间。既有手动节点位置不会覆盖；点「自动排列」清除手动位置后使用新默认布局。仅看主线时重新收紧纵向范围。

复制到自选 LLM 网站的完整提示词同步采用新字段。带任意新字段的手动回复必须满足全部新阅读字段与 Discussion 契约，防止半升级结果通过；旧版完整回复继续兼容。已保存旧阅读的缺失字段保持 nil，不从旧结果推造 Discussion、面板或连边；需要用原 PDF 重新生成并审阅。最终内容仍依赖所选模型与输出预算，未用真实论文评估科学抽取准确率。

## 工作流

### 0.12.0：复制提示词与手动带回结果

「PDF 研究图谱」新增「复制提示词」「粘贴模型结果…」，不依赖 API 连接或已配置模型。选择 PDF 并等待本机读取后，复制会把当前论文的全文提取文字、真实页码、文件名、SHA-256 前缀和当前语言的详细阅读／主线结论树契约送入剪贴板，不访问其他工作区内容、钥匙串或网络。用户自行粘贴到选定的 LLM 网站，网站隐私与输入输出上限由用户判断；软件不打开网站、不自动提交。

为只复制一次、带回一次，手动提示词要求依次判断研究类型、完成详细阅读、再构建主线与多级结论树，但在一个四字段 JSON 中返回 `source_fingerprint,study_type,analysis,graph`。API 流水线仍是三个独立调用，未改变第一阶段单标签约定。手动路径对两个嵌套对象复用相同规则：严格顶层／嵌套字段、类型一致、来源匹配、页码、语言、真实节点、无环、论证依据和禁止原子实验直连主线。指纹仅用于发现误粘贴，不证明模型忠实读取了这篇论文。

结果输入可直接粘贴，或主动点「从剪贴板粘贴」；不会自动读取剪贴板。支持完整 JSON 或单个完整 JSON 代码块，不从混杂解释中猜测 JSON；最多 2 MB。失败保留输入并提供「复制修复提示词」，不会自动调用模型；正确结果只进入已有待审阅预览，仍须用户另行点保存才写入文献库。会话固定所选 PDF 和语言，防止资料切换后误导入；关闭手动窗口会丢弃未导入输入，不作为自动恢复草稿持久化。

复制路径当前为文字版，不附带截图，也不声明解析了图像。无可读文字的页面会明确阻止复制，而非跳页；可先准备可搜索 PDF，或用已有 API 视觉补充路线。网站可能无法容纳长论文或完整 JSON，请按提示拆分；拆分结果目前需分别审阅，不自动合并。Assistant 通用操作、Protocol 和排程尚未添加手动复制导入入口，本轮只覆盖论文模块。

0.12.0 / build 15 的 125 项 XCTest 通过，包含手动交换新增 7 项测试：两种语言／复用契约、完整和 fenced JSON、来源与类型不一致、额外字段、页码、英文、原子实验捷径、空依据、截断／混杂／过大输入、无字页面以及修复提示词。release 与严格签名检查通过。GUI 已确认两个新入口；虚构测试 PDF 的文件面板关闭后 UI 自动化连接持续超时，尚未完成复制→粘贴→预览的人工点击链验收，不将自动测试或编译当作真实网站模型效果。

新增提示词字段必须由本机校验，而不是仅要求模型“输出 JSON”。此边界参考 [OpenAI Structured Outputs 官方文档](https://developers.openai.com/api/docs/guides/structured-outputs)；网站手动回复没有 API 层 Schema 保证。

### 0.10.0：先精读，再构建证据图谱

PDF 导入和 Assistant 的 `paper_analysis` 共用三阶段流水线：研究类型单标签判断 → 完整 `PaperAnalysis` JSON → 科学图谱 JSON。阅读记录包含题目、作者、年份、DOI、核心科学问题、背景缺口、全文概述、研究方法（模型/样品、干预、对照、指标、样本量、统计、图面板）、逐项发现（定量值、不确定性、方法引用、解释）、结论范围、局限与下一步可检验问题。资料未报告的细节保持空，不补造。

每项方法、发现及原文报告的语句必须有真实 1-based PDF 页码；推断标记 `inferred`，不当成作者报告。Swift 检查 JSON 顶层及嵌套字段、页码、方法引用、重复 ID、长度和输出语言。综述、方法、模拟、观察研究使用各自阅读规则，避免把参考文献实验或模拟误当成本文实测。分别调用阅读和图谱，让两种结构各自使用配置的输出预算；会增加模型调用数与费用，生成时显示具体阶段，可取消。没有调用真实模型验收科学准确率；仍需对照原文审阅。

Assistant 可直接分析带页码的 PDF 附件文字（原文含页码最多 100 万字符，任务连同资料最多 105 万字符），或重新读取阅读库中归档的原 PDF。当前消息完整进入分类与解析，较早会话另限最多 8 万字符。新的文献草稿不会自动写入自己的科学问题/实验库。直接在 Assistant 附上的提取文字目前不归档 PDF 原文件；需保留原件，若要本机归档请使用 PDF 导入页。文献阅读库提供“详细阅读 / 证据图谱”切换；旧记录没有详细阅读时仍显示旧图谱。

在侧栏打开「PDF 研究图谱」，或从文献阅读库进入。选择 PDF 后，App 用 PDFKit 在本机逐页提取数字文字；无文字或明显乱码的页面用 macOS Vision 离线 OCR。此时不向模型发送资料。选择模型并点「生成待审阅图谱」后，才把带页码与提取方法标记的文本发到用户配置的模型连接。若模型设置明确开启「支持图片输入」，还可选择最多 4 页截图、先预览，再把压缩 JPEG 作为 Chat Completions `image_url` data URL 随文字发送；从不上传原始 PDF。模型返回严格 JSON：`title`、`detail`、`claims`、`atomic_experiments`、`evidence_links`、`claim_links`。图谱先只读预览，也可以导出原始提案 JSON。用户点「审阅后存入文献阅读库」后，图谱写入本机 SQLite 工作区，原 PDF 保存于本机 `LiteraturePDFs` 目录。旧版误存于科学问题库的 PDF 图谱在启动时自动迁入文献阅读库，迁移前保存 `before-literature-migration.json` 备份；旧记录若未归档 PDF，需从原位置另行打开。

英文语言模式使用独立英文提示词，要求所有新生成的自然语言字段为英文；中文模式使用中文提示词。两者的 JSON 键与枚举保持固定英文标识。旧资料与 PDF 原文不会在工作区里被静默翻译。

## 科学与安全边界

- BioRA 0.13.4 的「尚无图面板逻辑」新增局部补充入口（文献阅读库及 PDF 草稿）：复制专用提示词到自选 LLM 网站，粘贴七字段 `exchange_id,reading_id,source_fingerprint,methods,findings,figure_panels,panel_links` JSON，本机校验后预览，再显式保存。方法和发现只追加必要新记录；已有阅读摘要、Discussion、书目、主线图及节点位置保持不变。回应须匹配本次交换和选中文献，严格检查嵌套结构／引用／页码／新生成字段语言；旧阅读含中文不因切到英文而改写。错误可复制修复提示词。保存前若原阅读被修改或已补充则拒绝覆盖，复制／粘贴／预览不写库。没有 detailed reading 的旧图谱可以形成明确标为图面板补充的部分记录，不伪称完成全文精读。
- 补充提示词可包含用户粘贴的图注或本机提取文字（仍限100万字符）；可读取同一篇或已归档 PDF，校验 SHA-256 摘要及已有页数，缺失页不静默省略。未附原文时提示用户在其 LLM 网站自行提供原 PDF／图注；仅旧阅读不能替代原图证据。不自动打开网站、不发 API 请求、不复制 Key 或工作区其他内容；提示词没有截图。图像能力和资料隐私由用户自选网站承担，页码与科学关系仍需人工对照核实。
- 0.13.3 新生成图谱不再允许“先保留未关联结果”：中英文精读／图谱／网站复制提示词逐Results小节、图表面板、比较、对照和负结果清点，并将发现逐项归入主线问题与多级结论树。新增本机有向可达性校验：每个论断须通向主线，每个已记录实验须经下层结论通向 `role=result`，不能仅挂 Discussion；详细阅读已有发现时禁止空图或 Discussion-only 图。API 失败最多定向修复一次；手动粘贴失败可复制修复提示词。独立 Protocol、本人科学问题草稿、未来 planned 检验及旧已保存图谱不被强制补线或重写。连通性校验不等于科学论证正确，也无法机械证明原文没有漏读；语义覆盖仍需用户审阅，不能为了通过而编造依据。
- `recorded` 只用于论文确实报告的方法与观察，必须有 PDF 内真实页码；缺少结果或尚未执行的检验标为 `planned`，不能连为证据。
- 每个文献节点的出处写入 PDF 文件名、SHA-256 前缀与页码，并明确标注这是 AI 提取的文献记录、不是本人实验。页码仍需用户回到原文核对。
- 导入论断的 50%「自评」只是为了兼容现有图谱数据结构的中性占位值，并非模型置信度或论文证据强度；导入后应逐条编辑。
- 不准把试剂、材料、仪器或 Protocol 的一个操作当成“原子实验”。支持/反驳边只是模型提出的解释，不能自动表示统计证明或因果关系；不允许悬空、重复或成环的关系。
- PDF 内容是不可信资料，不授权改变提示词、输出格式或写入动作。解析阶段不会调用工具或写库；结构与引用由本机再次验证，错误最多定向修复一次。
- PDFKit/Vision 是零额外运行时的轻量路线，不提供专用文档模型级别的双栏重排、复杂表格或公式恢复。扫描 OCR 也可能认错基因符号、数值和单位；用户需回到 PDF 核对。无法识别的页必须选入视觉截图，否则拒绝生成，不会静默跳页。文本模型不接收图片，视觉模型仍可能看错图表。
- 单文件最多 20 MB、120 页、100 万字符（含页码与提取方式标记）。本机读取、API 分阶段解析、复制提示词和助手 PDF 附件使用同一上限；图片仍最多 4 页、每页压缩 JPEG 不超过 1 MB。超过上限明确拒绝，不静默截断。最终输出还受用户所选模型的上下文和输出 token 设置限制；较长原文会在多个解析阶段发送，费用增加，不自动拆分文本或提高模型 token 设置。不同 OpenAI-compatible 服务对 `image_url` 支持不一，开启能力开关前应核对其文档。

## 方案选择（2026-09）

没有适合所有科学 PDF 的单一「最强」解析器。Docling 支持本机运行、版面/阅读顺序、表格、公式和 OCR，其代码为 MIT，但模型许可需另核；MinerU 擅长复杂学术 PDF、公式与表格并支持本机 OCR，但当前仓库使用带附加条件的 MinerU Open Source License，不能视为纯 Apache-2.0；PyMuPDF4LLM 支持版面与混合 OCR，但其 AGPL/商业双许可证不适合不经合规审查就打包进本项目。为保持原生 Swift、轻量安装和项目的 Apache-2.0 发行边界，0.9.0 默认实现是 Apple PDFKit + Vision 的本机混合读取，复杂页面由用户显式选择截图给视觉模型。它不是对上述专用解析器精度的宣称。

参考：[Docling 项目与许可](https://github.com/docling-project/docling)、[MinerU 项目与许可](https://github.com/opendatalab/MinerU)、[PyMuPDF4LLM 功能](https://pymupdf.readthedocs.io/en/latest/pymupdf4llm/index.html)、[PyMuPDF 许可](https://pymupdf.readthedocs.io/en/latest/faq/index.html)、[Apple PDFPage](https://developer.apple.com/documentation/PDFKit/PDFPage)、[OpenAI 图片输入格式](https://developers.openai.com/api/docs/guides/images-vision)。

## 画布交互

鼠标仅在实际图谱画布内悬停时，普通滚动平移图谱、⌘＋滚动缩放；在标题、工具栏、节点详情及画布外的审阅内容上滑动，事件交还页面，正常滚动即可，不需按 Control。被外层滚动裁掉的画布不接管事件。

主科学问题页现在有「专注图谱」视图。拖动空白背景平移画布，单击空白处关闭节点详情，直接拖动节点卡片调整位置；双指捏合、按住 ⌘ 滚轮、⌘＋加减号或按钮可缩放，点「适合窗口」找回图谱。点击节点看出处，悬停或选中时突出与该节点相连的证据链；「自动排列」可恢复默认位置。PDF 草稿与文献阅读库复用同一图谱，节点位置可调整，文献内容仍只读。

后续要进一步提升大图体验，可增加搜索定位、折叠分支和小地图；要提升证据质量，应结构化样本量、对照、测量值、统计检验及原始附件，并对论文页码做更强的逐项核对。当前版本不自动评价研究真伪。
